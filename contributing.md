# Как добавить проект

Спасибо, что хотите пополнить список.

## Что подходит

- Открытый исходный код в публичном репозитории.
- Инструмент имеет отношение к работе продавца на Ozon, Wildberries или Яндекс.Маркете: клиент API, MCP-сервер, репрайсер, аналитика, работа с отчётами.
- Понятно, что он делает, — есть README хотя бы на одном языке.

Заготовки, форки без изменений и репозитории без единого коммита за два года не добавляем. Архивированные проекты оставляем только там, где они всё ещё полезны как справочник, — с пометкой 🗄️.

## Что не подходит

- Закрытые сервисы — им отведён отдельный раздел без оценок, туда добавляем только то, чем реально пользуются продавцы.
- Инструменты, построенные на парсинге витрин площадок: правила Ozon это прямо запрещают, и ответственность ложится на владельца кабинета.

## Формат строки

```markdown
- [автор/репозиторий](https://github.com/автор/репозиторий) — язык, лицензия, ⭐звёзды. Одно предложение о том, что он делает.
```

Без маркетинга и превосходных степеней. «Асинхронный клиент с лимитами и автоповторами» лучше, чем «мощнейшая библиотека для работы с API».

Пометки: 🗄️ — архивирован автором, 💤 — без коммитов больше года.

## Свои проекты

Добавлять можно. Просто скажите об этом в описании пул-реквеста — это нормально и не требует оправданий.

## Порядок

Внутри разделов — по числу звёзд, по убыванию. Так не приходится спорить о том, что «лучше».
